# Northbridge Accounting (demo)

A demo small-business website for a fictional Minneapolis accounting firm. Portfolio project by Brianna P.

**Live:** https://northbridgeaccounting.dev

- Built in **WordPress + Elementor** (Hello Elementor theme, Contact Form 7)
- Custom WordPress plugin (`wp-content/plugins/northbridge-site`) for design tokens, fonts, header behavior, scroll reveals and page transitions
- Responsive, with WCAG AA text contrast
- Deployed here as a static export; forms run in demo mode

Northbridge Accounting is a fictional business and does not provide accounting or tax services.
